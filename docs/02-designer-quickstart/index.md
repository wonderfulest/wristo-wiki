# Wristo Designer Quickstart Hub

This module is designed for designers who are new to Wristo and helps you go from 0 to 1 by:

- Understanding what Wristo is and who it is for
- Completing account registration and your first console walkthrough
- Designing and publishing your first watch face
- Learning the basic design guidelines, asset usage, and data logic
