# Assets & Resources

- **Upload image assets**  
  - Upload PNG/JPG image assets in "Asset Management".  
  - When naming assets, use meaningful English or pinyin names (for example, `bg-sunset-01`).

- **Use built-in assets**  
  - If Wristo provides official icon/background libraries, you can search and insert them directly in the editor.  
  - Built-in assets are usually optimized for size and performance and are recommended as the first choice.

- **Image size and performance tips**  
  - Resolution: keep it close to or equal to the target device resolution to avoid unnecessarily large packages.  
  - Compression: compress images appropriately while preserving visual quality.  
  - Avoid using many huge PNGs or complex translucent overlays, as they may hurt performance and battery life.

- **Background design tips**  
  - Ensure there is enough contrast in areas where time and key data are displayed.  
  - Avoid placing high-contrast, complex textures directly behind time and numerical data.  
  - Consider designing a dedicated "information panel" behind key information to improve readability.
