# 四、Search 权重配置（决定搜索质量）

### 1️⃣ 可搜索字段顺序（= 隐性权重）

```
curl -X PUT 'http://localhost:7700/indexes/watchfaces/settings/searchable-attributes' \
-H 'Authorization: Bearer your_master_key' \
-H 'Content-Type: application/json' \
--data-binary '[
  "name",
  "tags",
  "scene",
  "desc"
]'
```

👉 **name > tags > scene > desc**

------

### 2️⃣ 可过滤字段（必须）

```
curl -X PUT 'http://localhost:7700/indexes/watchfaces/settings/filterable-attributes' \
--data-binary '[
  "category",
  "locale"
]'
```

支持：

```
keyword + category=digital + locale=en
```

------

### 3️⃣ 排序规则（商业价值 > 相关性）

```
curl -X PUT 'http://localhost:7700/indexes/watchfaces/settings/ranking-rules' \
--data-binary '[
  "words",
  "typo",
  "proximity",
  "attribute",
  "sort",
  "exactness",
  "desc(downloads)",
  "desc(rating)",
  "desc(updated_at)"
]'
```

👉 热门 + 好评 + 新 = 更靠前

# 八、索引更新策略（非常重要）

### ❌ 不要

- 每次搜索查 MySQL
- 全量 rebuild

### ✅ 正确做法

#### 表盘发布 / 修改

```
生成 search_profile
→ updateDocument(id)
```

#### 定时任务（每天）

```
只更新 downloads / rating / updated_at
```
