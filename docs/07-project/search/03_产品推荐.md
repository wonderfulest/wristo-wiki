# Step 4️⃣ ❌ 不用 View，改为「关键词评分表」

## 🎯 目标

- 每天 **固定公式打分**
- 分数可追溯、可对比
- 后续你可以 **随时调权重重算**

------

## Step 4.1 建表：product_keyword_score

```
CREATE TABLE product_keyword_score (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,

  product_keyword VARCHAR(255) NOT NULL,

  search_times INT NOT NULL,
  user_cnt INT NOT NULL,
  avg_results DECIMAL(10,2),
  zero_result_times INT,

  product_score DECIMAL(10,2) NOT NULL,

  stat_date DATE NOT NULL,

  created_time DATETIME DEFAULT CURRENT_TIMESTAMP,

  UNIQUE KEY uk_keyword_date (product_keyword, stat_date),
  KEY idx_score (product_score)
);
```

> 💡 关键点
>
> - **stat_date**：允许你看趋势、回溯历史
> - 所有原始指标 **冗余存一份**（避免回表）

------

## Step 4.2 每日打分 SQL（核心）

```
INSERT INTO product_keyword_score (
  product_keyword,
  search_times,
  user_cnt,
  avg_results,
  zero_result_times,
  product_score,
  stat_date
)
SELECT
  product_keyword,
  search_times,
  user_cnt,
  avg_results,
  zero_result_times,

  (
      search_times * 1.0
    + user_cnt * 2.0
    + zero_result_times * 2.5
    - avg_results * 1.5
  ) AS product_score,

  stat_date
FROM product_keyword_candidate
WHERE stat_date = CURDATE()
ON DUPLICATE KEY UPDATE
  search_times = VALUES(search_times),
  user_cnt = VALUES(user_cnt),
  avg_results = VALUES(avg_results),
  zero_result_times = VALUES(zero_result_times),
  product_score = VALUES(product_score);
```

# Step 5️⃣ ❌ 不用 View，直接输出「我该做什么产品」

## 🎯 目标

- 输出 **明确行动建议**
- 给你一个 **可直接用的产品清单**
- 不是分析，是 **决策结果**

------

## Step 5.1 建表：product_action_suggestion

```
CREATE TABLE product_action_suggestion (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,

  product_keyword VARCHAR(255) NOT NULL,
  product_score DECIMAL(10,2) NOT NULL,

  suggestion VARCHAR(32) NOT NULL,

  stat_date DATE NOT NULL,
  created_time DATETIME DEFAULT CURRENT_TIMESTAMP,

  UNIQUE KEY uk_keyword_date (product_keyword, stat_date),
  KEY idx_suggestion (suggestion),
  KEY idx_score (product_score)
);
```

------

## Step 5.2 生成「开发建议清单」SQL

```
INSERT INTO product_action_suggestion (
  product_keyword,
  product_score,
  suggestion,
  stat_date
)
SELECT
  product_keyword,
  product_score,

  CASE
    WHEN product_score >= 30 THEN '立即做'
    WHEN product_score >= 20 THEN '高优先'
    WHEN product_score >= 10 THEN '观察'
    ELSE '暂不考虑'
  END AS suggestion,

  stat_date
FROM product_keyword_score
WHERE stat_date = CURDATE()
ON DUPLICATE KEY UPDATE
  product_score = VALUES(product_score),
  suggestion = VALUES(suggestion);
```

------

## Step 5.3 你现在每天能直接看的表

### 🔥 今天该做什么产品？

```
SELECT *
FROM product_action_suggestion
WHERE stat_date = CURDATE()
  AND suggestion IN ('立即做', '高优先')
ORDER BY product_score DESC;
```

### 🔥 观察池（潜在机会）

```
SELECT *
FROM product_action_suggestion
WHERE stat_date = CURDATE()
  AND suggestion = '观察'
ORDER BY product_score DESC;
```
