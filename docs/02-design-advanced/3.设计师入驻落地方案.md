## 一、核心原则（先对齐方向）

你这套机制，**一定要坚持这 4 个原则**，否则后期会炸：

1. **不审批设计师，只审批数据**
2. **不开“特例”通道**
3. **权限是状态，不是身份**
4. **退出 ≠ 封号，而是权限回退**

你现在写的文案已经完全符合这四点，下面就是把它“系统化”。

------

## 二、产品层：把路线图变成「状态机」

### 1️⃣ 设计师不是“一个角色”，而是一个 **状态**

建议你内部定义一个极简状态枚举：

```
DesignerStage =
  | FREE_CREATOR
  | VALIDATED_CREATOR
  | PRO_CREATOR
  | SUSTAINABLE_CREATOR
```

⚠️ **前端 & 后端都只认这个状态，不认“设计师级别”这种人为概念。**

------

### 2️⃣ 每个状态，只影响「按钮权限」

| 能力 / 状态 | Free | Validated | Pro  | Sustainable |
| ----------- | ---- | --------- | ---- | ----------- |
| 使用设计器  | ✅    | ✅         | ✅    | ✅           |
| 发布免费    | ✅    | ✅         | ✅    | ✅           |
| 发布付费    | ❌    | ❌         | ✅    | ✅           |
| 新增付费    | ❌    | ❌         | ✅    | ⚠️可暂停     |
| 结算收益    | ❌    | ❌         | ✅    | ✅           |

👉 **注意**：
 你不是“禁止设计”，你只是 **禁用某几个按钮**。

这点非常重要。

------

### 3️⃣ 设计师后台一定要有「进度条」

你已经在文案里写了这句话，这是**整个机制的灵魂**：

> ```
> 还差 132 次下载解锁付费
> ```

落地建议：

- 首页顶部展示：
  - 当前阶段（高亮）
  - 下一阶段条件
  - 当前进度（实时）

这一步 = **把焦虑变成目标感**。

## 三、技术层：全部自动化，不走人工

### 1️⃣ 下载量 & 权限解锁：100% 自动

每天一个定时任务即可：

```
for each designer:
  if stage < PRO_CREATOR:
    if any_app_download >= 1000 OR total_download >= 10000:
      stage = PRO_CREATOR
      unlock_paid_publish()
```

- ❌ 不需要人工确认
- ❌ 不需要通知审核
- ✅ 自动发一封「解锁通知邮件」

------

### 2️⃣ 退出机制：不是“踢人”，而是“回退能力”

你定义的规则非常聪明，建议 **技术这样实现**：

#### 🔄 条件检测（每月跑一次）

```
if designer.stage >= PRO_CREATOR:
  if paid_income < $100
     AND no_update >= 3-6 months:
       disable_paid_publish()
```

⚠️ 注意：

- **不要改 stage**
- 只是加一个 flag：

```
canPublishPaid = false
```

#### 🔓 重新激活条件

```
if designer uploads new work:
  re-enable paid publish
```

👉 这点极其重要：

> **设计师永远有“翻身按钮”**

> 🎉 恭喜！你的作品已获得用户认可，付费发布权限已自动解锁。

⚠️ 暂停新增付费通知（非常关键）：

> 我们注意到你最近一段时间创作较少。

>  **上传新作品后将立即恢复。**

❌ 永远不要出现：

- “不符合要求”
- “不达标”
- “平台决定”
