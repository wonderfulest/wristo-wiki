# ① **最外圈：TACHYMETER（测速计刻度）**

这是机械计时码表最经典的功能，用来根据计时秒数计算速度。

你表盘上最外圈写着 **TACHYMETER**，四周刻度为：

- 400
- 350
- 300
- 250
- 220
- 200
- 180
- 160
- 140
- 120
- 100
- …（依次递减）

### 📌 它的作用是：

用 **计时秒数（Chronograph，秒针）** 来计算 **单位距离的平均速度**。

### 公式：

如果在 **1 公里**（或 1 英里）内完成的时间为 *t* 秒：

```
Tachymeter 速度 = 3600 ÷ t
```

例如：

- 若跑 1 km 用 **30 秒** → Tachymeter 指向 **120** → 表示 **120 km/h 平均速度**
- 若 45 秒 → 指向约 **80** → 表示 **80 km/h**

### 💡 这一圈刻度只与“计时用的秒针”配合，不等同于普通走时秒针。

------

# ② **内圈：分钟/秒钟刻度（普通读时刻度）**

你表盘第二圈是 **标准的 0–60 刻度**，用于读取：

- **分钟（Minute hand）**
- **秒钟（Second hand）**

刻度的特征：

- 每 1 秒 或 1 分钟一个细刻度
- 每 5 秒（或 5 分钟）变成粗刻度 + 橙色方块标记
- 上方的 **60** 是分钟/秒钟的起点

------

# ③ **第三圈：倾斜排列的大数字（05, 10, 15, 20…）**

这些是用于 **计时功能（Chronograph）** 的分读数，通常搭配子盘使用。

特点：

- 数字随表圈弧度“倾斜”对齐
- 用来快速读取计时的秒/分
- 多为 **5 的倍数**

------

# ④ 子表盘的含义（补充说明）

你图片中有两个小表盘：

左侧小盘：

- 多半为 **计时分钟（Chronograph Minutes）**
- 或 **小秒针（Running Seconds）**

右侧小盘：

- 多半为 **计时小时（Chronograph Hours）**
- 或 **计时秒钟（Chronograph Seconds）**

机械计时码表的搭配很多，这种双盘布局较常见。

------

# ⭐ 总结（超级重要）

你的表盘 **四周“从外向内”的刻度结构”如下**：

| 位置       | 刻度内容              | 含义                                        |

| **最外圈** | Tachymeter（400–100） | 测速刻度，用于计时秒针                      |
