# 设计师快速开始（Wristo Designer Quickstart）

> 面向第一次接触 Wristo 的设计师，预计阅读时间 10–15 分钟。

---

## 1️⃣ 设计师入门（Getting Started）

- **Wristo 是什么？**  
  Wristo 是一个面向设计师与开发者的「表盘设计与发行平台」，帮你把创意快速变成可在各大智能手表平台（如 Garmin 等）运行的表盘产品。
- **我可以在 Wristo 做什么？**  
  - 设计并管理多个表盘项目。
  - 使用可视化编辑器完成布局、配色、字体等设计工作。
  - 绑定数据字段（步数、心率等），制作既好看又好用的表盘。
  - 导出并发布到支持的平台，持续维护和更新。
- **支持哪些设备与平台？（示例）**  
  - Garmin 系列设备（不同分辨率与机型）。  
  - 后续会根据平台支持情况持续扩展（以实际文档为准）。
- **谁适合使用 Wristo？**  
  - 设计师：有 UI/视觉基础，希望快速做出可上架的表盘。  
  - 开发者：需要在现有表盘上定制视觉与交互。  
  - 商家 / 品牌方：希望打造品牌专属表盘资产。

## 2️⃣ 注册与账号准备（Account Setup）

- **注册 Wristo 账号**  
  - 访问 Wristo 官网，点击「注册」或「成为设计师」。  
  - 填写邮箱、密码和基础信息，提交后等待验证邮件。
- **邮箱验证与登录**  
  - 打开注册邮箱，找到 Wristo 的验证邮件并点击验证链接。  
  - 验证成功后，使用邮箱 + 密码登录 Wristo 控制台。
- **账号类型说明（设计师 / 商家）**  
  - 设计师账号：以个人创作、作品集和收益为主。  
  - 商家账号：更偏向团队协作、品牌运营和批量表盘管理。  
  - 具体权益与差异请参考《设计师入驻规则》与相关文档。
- **常见注册问题**  
  - 收不到邮件：
    - 检查垃圾邮箱 / 广告邮箱。  
    - 确认邮箱是否填写正确，再次请求发送验证邮件。  
  - 登录失败：
    - 确认邮箱、密码无误。  
    - 尝试「忘记密码」重置。  
    - 仍无法登录时，可按文档指引提交工单或联系支持。

## 3️⃣ 控制台快速认识（Dashboard Overview）

- **控制台界面总览**  
  登录后你将进入 Wristo 控制台，这是你管理表盘、资源和账号的「工作台」。
- **核心模块说明（示例）**  
  - 项目 / 表盘：查看和管理你创建的所有表盘项目。  
  - 设计编辑器：打开具体表盘项目后进入，可视化编辑画布。  
  - 资源管理：统一管理上传的图片、字体等素材。  
  - 账号与结算：查看个人信息、收益与结算方式（如有）。
- **新手建议的操作顺序**  
  1. 先浏览「项目 / 表盘」列表，熟悉项目结构。  
  2. 点击「新建表盘」，体验一次完整的创建流程。  
  3. 在编辑器中尝试修改背景、时间样式等。  
  4. 再逐步了解「资源管理」「导出与发布」等高级功能。

## 4️⃣ 第一个表盘（Your First Watch Face）

> 这是整个快速开始中最关键的一节，建议跟着一步一步做完。

- **创建第一个表盘**  
  - 在控制台点击「新建表盘」或类似入口。  
  - 为项目命名（例如：`My First Wristo Watchface`）。
- **选择设备与分辨率**  
  - 从支持的设备列表中选择目标设备（如某款 Garmin 机型）。  
  - 对应分辨率会自动带出，也可在后续阶段配置多分辨率适配。
- **使用模板 vs 从空白开始**  
  - 使用模板：
    - 适合第一次上手，快速理解布局与组件。  
    - 选择一个接近你目标风格的模板，替换图片与颜色即可。  
  - 从空白开始：
    - 适合有成熟设计方案或较强设计经验的用户。  
    - 自行规划网格、排版和信息层级。
- **保存与预览**  
  - 在编辑器中完成基础设计后，点击「保存」。  
  - 使用内置预览功能查看表盘在目标设备上的展示效果。  
  - 建议在每次关键修改后都进行一次预览，避免后期返工。

## 5️⃣ 表盘设计基础（Design Basics）

- **画布与安全区域说明**  
  - 画布尺寸 = 设备分辨率（如 390×390）。  
  - 安全区域：为避免被设备系统 UI、边缘圆角或传感器遮挡，关键信息（时间、数据）应放在推荐的安全区域内。  
  - 建议在编辑器中始终打开「安全区域」辅助线。
- **常见表盘元素介绍**  
  - 时间：整个表盘的视觉主角，需保证高对比度与可读性。  
  - 日期：通常与时间组合展示，注意字号层级。  
  - 数据项：步数、心率、卡路里、电量等，宜分组展示，避免信息噪声。  
  - 图标与装饰：辅助传达风格，但不应抢占信息主视觉。
- **图层与对齐**  
  - 善用图层顺序管理前后关系（背景 / 数据 / 装饰）。  
  - 使用对齐工具（居中 / 网格 / 等间距）保证布局整洁。  
  - 尽量遵守「对齐—对比—留白」三大基础视觉原则。
- **字体与颜色规范**  
  - 字体：优先使用可读性强的无衬线字体，避免过度花哨。  
  - 颜色：
    - 文字与背景保持足够对比，支持在强光环境下可读。  
    - 控制全局主色 1–2 个，辅助色 2–3 个即可。  
  - 如 Wristo 提供官方字体与色板，请优先参考《设计规范》文档。

## 6️⃣ 使用素材与资源（Assets & Resources）

- **上传图片资源**  
  - 在「资源管理」中上传 PNG/JPG 等图片素材。  
  - 为资源命名时建议使用有语义的英文或拼音（如 `bg-sunset-01`）。
- **使用内置素材**  
  - 若 Wristo 提供官方图标库 / 背景库，可直接在编辑器内搜索和插入。  
  - 内置素材通常已经过尺寸与性能优化，优先推荐使用。
- **图片尺寸与性能建议**  
  - 分辨率：接近或等于目标设备分辨率即可，避免远超分辨率导致包体过大。  
  - 压缩：在保证视觉效果的前提下适度压缩。  
  - 避免使用大量超大 PNG 或半透明叠加，以免影响性能与续航。
- **背景图设计技巧**  
  - 确保时间和关键信息区域有足够对比度。  
  - 避免在时间和数字后面放置高对比度复杂纹理。  
  - 可以为主信息区域单独设计一块「信息底板」，提升可读性。

## 7️⃣ 数据与动态元素（Data & Logic）

- **数据字段说明（示例）**  
  - 步数、心率、卡路里、楼层、距离、电量、天气等。  
  - 不同平台支持的数据字段可能有所不同，请以平台文档为准。
- **数据绑定方式（概念）**  
  - 在编辑器中选中组件（如文本），将其绑定到对应数据字段。  
  - 可设置显示格式（如 24/12 小时、单位、前缀/后缀）。
- **条件显示与状态切换（如果平台支持）**  
  - 根据设备状态（运动中/静止、白天/夜间、电量高/低）切换不同样式。  
  - 用于实现例如：低电量简化模式、夜间深色模式等。  
  - 详细配置方式请参考后续高级教程或平台文档。
- **常见数据异常说明**  
  - 数据为空 / 为 0：可能是设备当天未记录、权限未授权或模拟器环境限制。  
  - 与真机不一致：注意模拟器、历史数据与实时数据之间的差异。  
  - 建议在真机多场景测试，包括运动 / 静止、白天 / 夜间等。

## 8️⃣ 预览、导出与测试（Preview & Export）

- **在线预览**  
  - 使用编辑器内的预览功能检查整体排版、颜色与数据位置。  
  - 建议在不同比例（缩放）下预览，模拟真实佩戴距离。
- **不同设备适配检查**  
  - 若一个表盘支持多设备分辨率：
    - 逐一检查每种分辨率下是否有元素被裁切或遮挡。  
    - 核对安全区域与边缘留白。  
  - 必要时为不同分辨率制作微调版本。
- **导出配置（如 `conf.json`）**  
  - 完成设计后，根据平台要求导出配置和资源包。  
  - `conf.json` 等配置文件中通常包含：分辨率、数据绑定、资源路径等信息。  
  - 导出前确保：项目命名规范、版本号更新、平台必填字段已完整。
- **测试常见问题**  
  - 模拟器显示正常但真机异常：检查设备型号、系统版本与权限。  
  - 动画 / 动态效果卡顿：尝试减少图层数量、压缩图片、简化逻辑。  
  - 颜色偏差：在真实户外环境下观察，以便调整对比度与亮度。

## 9️⃣ 发布与后续（Next Steps）

- **发布到平台（以 Garmin 为例）**  
  - 按照平台流程上传资源包与配置文件。  
  - 填写表盘名称、简介、标签、预览图等信息。  
  - 提交审核并等待平台结果。
- **表盘更新与版本管理**  
  - 每次更新表盘建议：
    - 在 Wristo 中保留历史版本（或使用版本号管理）。  
    - 在配置文件中更新版本号与更新说明。  
  - 避免直接覆盖线上版本而不留备份，便于回滚。
- **用户反馈与迭代建议**  
  - 根据用户评价与数据（下载量、留存等）调整设计。  
  - 建议以小步快跑方式迭代：一次只改少量关键点，持续观察效果。
- **商业化路径（如果有）**  
  - 若平台支持付费表盘或内购：
    - 关注定价策略与目标人群。  
    - 平衡个性化设计与大众审美。  
  - 具体规则与分成方式请参考《设计师入驻规则》《设计师入驻落地方案》等文档。

## 🔟 常见问题（FAQ）

> 以下为新手设计师常见疑问的示例，具体问题可在后续不断补充完善。

- **Q1：第一次做表盘，推荐从哪里开始？**  
  A：建议从「模板 + 少量自定义」开始，先把一次完整的创建—预览—导出—发布流程跑通，再去做复杂创意。

- **Q2：为什么模拟器里很好看，真机上效果一般？**  
  A：可能原因包括：屏幕实际亮度与对比度、户外强光环境、表带与肤色搭配、分辨率缩放等。建议多在真机、多场景下观察，并预留足够对比度和留白。

- **Q3：表盘卡顿或耗电严重怎么办？**  
  A：检查是否存在：
  - 大量超大尺寸 PNG 或复杂透明叠加。  
  - 过多高频动画或实时刷新元素。  
  - 不必要的数据计算逻辑。  
  尝试精简资源与逻辑，优先保证核心信息体验。

- **Q4：设备上显示的数据不对 / 不更新？**  
  A：
  - 确认设备本身是否有记录相应数据。  
  - 检查数据绑定是否正确。  
  - 确认平台权限、同步状态是否正常。

- **Q5：有 Bug 或显示异常如何反馈？**  
  A：
  - 先记录设备型号、系统版本、表盘版本、问题截图或视频。  
  - 按文档中提供的渠道（工单系统 / 邮箱 / 社群）提交。  
  - 建议附上导出的配置文件或项目信息，便于排查。
