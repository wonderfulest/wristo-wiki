# 🎯 **Garmin 指针 SVG 自动化生成模板（可复用 Prompt）**

以下是你的可复用模板，
 你只需要改动 `{参数}` 部分即可自动生成一套专业可用的表盘指针 SVG。

------

# ✅ **自动化 Prompt 模板**

```
请为我生成一套 Garmin 表盘指针（Hour 手、Minute 手、Second 手）+ Center Cap 的 SVG 素材。

【整体主题风格】
主题风格为：{主题名称，例如：Christmas / Nordic Minimalism / Retro Mechanical / Aviation Pilot / Business Classic}

请根据主题风格自动设计适合的材质、配色、边缘处理、渐变方案，确保整套指针视觉风格统一。

------------------------------------------------------------
【输出要求】
- 输出 4 个独立 SVG：
  - Hour Hand
  - Minute Hand
  - Second Hand（需要包含 Counterweight）
  - Center Cap
- 每个 SVG 必须是独立完整的 <svg>...</svg>
- 不要输出任何注释或说明性文字，只输出 SVG 代码

------------------------------------------------------------
【SVG 画布规格】
所有指针的 SVG 必须使用以下画布设置：

width="454"
height="454"
viewBox="0 0 454 454"

------------------------------------------------------------
【旋转点（极其重要）】
所有指针的旋转中心必须严格位于：

x = 227
y = 227

要求：
- 指针底部中心点必须精确落在 (227, 227)
- 所有旋转计算基于该点，不得偏移
- 指针主体沿 y 轴向上延伸（默认指向 12 点方向）

------------------------------------------------------------
【尺寸比例（可调整）】
请根据主题自动优化设计，但需遵守以下基础参数：

Hour Hand:
- 宽度：{12–16}
- 高度：{150–200}

Minute Hand:
- 宽度：{8–12}
- 高度：{200–260}

Second Hand:
- 宽度：{2–4}
- 高度：{260–320}
- 底部包含主题化 Counterweight（可定制造型）

Center Cap:
- 完全圆形，直径：{20–40}

参数允许微调，但必须保持成套协调。

------------------------------------------------------------
【SVG 技术规范】
- 可以使用 <rect>、<polygon>、<circle>、<path>
- 可以使用 <linearGradient> 和 <radialGradient>
- 不使用外部字体
- 禁止使用复杂 filter/mask（除非必须且结构非常简洁）
- 颜色与渐变应便于后期在 Figma 中编辑

------------------------------------------------------------
【设计要求】
请输出具有以下特点的指针：

- 风格统一，符合主题调性
- 外轮廓清晰、层次明确
- 渐变结构合理
- 形状便于后续编辑（尽量不使用过于复杂的曲线）
- 保证 SVG 在 Figma 中可直接复制使用

------------------------------------------------------------
【最终输出格式】
请依次输出：

<svg>（Hour Hand）</svg>
<svg>（Minute Hand）</svg>
<svg>（Second Hand）</svg>
<svg>（Center Cap）</svg>

每个 SVG 必须独立输出，不要放在一起。
```

# 🚀 使用示例：如何快速生成一套新主题指针？

例如：

**我要一套北欧极简风的指针：**

```
主题名称 = Nordic Minimalism
尺寸维持默认
风格要求：极简、无阴影、双色系统、低饱和度
```

把这些填进模板即可立即生成全套 SVG。
