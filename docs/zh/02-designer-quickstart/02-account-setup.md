# 注册与账号准备（Account Setup）

## **注册 Wristo 账号** 

打开设计平台，注册账号

https://studio.wristo.io/

发送邮件，表达想入驻 Wristo 成为设计师，说明为已注册的哪个邮箱账号开通设计师权限，最好附带作品，

## 注册**佳明（Garmin）开发者账号**  

  - 若你计划将表盘发布到 Garmin 平台，建议：  
    - 先在 Garmin 官方渠道注册 / 准备好个人 Garmin 账号。  
    - 建议优先使用 **与 Wristo 相同的邮箱**，方便账号管理。

    Garmin 账号则用于在 Garmin 生态中发布与管理你的表盘作品，两者相互配合使用。
