# 注册与账号准备（Account Setup）

- **注册 Wristo 账号**  
  - 访问 Wristo 官网，点击「注册」或「成为设计师」。  
  - 填写邮箱、密码和基础信息，提交后等待验证邮件。

- **邮箱验证与登录**  
  - 打开注册邮箱，找到 Wristo 的验证邮件并点击验证链接。  
  - 验证成功后，使用邮箱 + 密码登录 Wristo 控制台。

- **账号类型说明（设计师 / 商家）**  
  - 设计师账号：以个人创作、作品集和收益为主。  
  - 商家账号：更偏向团队协作、品牌运营和批量表盘管理。  
  - 具体权益与差异请参考《设计师入驻规则》与相关文档。

- **佳明（Garmin）账号准备说明**  
  - 若你计划将表盘发布到 Garmin 平台，建议：  
    - 先在 Garmin 官方渠道注册 / 准备好个人 Garmin 账号。  
    - 建议优先使用 **与 Wristo 相同的邮箱**，方便后续通知与对账。  
  - Wristo 账号用于在 Wristo 平台内创作与管理表盘；  
    Garmin 账号则用于在 Garmin 生态中发布与管理你的表盘作品，两者相互配合使用。

- **常见注册问题**  
  - 收不到邮件：
    - 检查垃圾邮箱 / 广告邮箱。  
    - 确认邮箱是否填写正确，再次请求发送验证邮件。  
  - 登录失败：
    - 确认邮箱、密码无误。  
    - 尝试「忘记密码」重置。  
    - 仍无法登录时，可按文档指引提交工单或联系支持。
