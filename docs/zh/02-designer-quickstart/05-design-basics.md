# 表盘设计基础（Design Basics）

- **画布与安全区域说明**  
  - 画布尺寸 = 设备分辨率（如 390×390）。  
  - 安全区域：为避免被设备系统 UI、边缘圆角或传感器遮挡，关键信息（时间、数据）应放在推荐的安全区域内。  
  - 建议在编辑器中始终打开「安全区域」辅助线。

- **常见表盘元素介绍**  
  - 时间：整个表盘的视觉主角，需保证高对比度与可读性。  
  - 日期：通常与时间组合展示，注意字号层级。  
  - 数据项：步数、心率、卡路里、电量等，宜分组展示，避免信息噪声。  
  - 图标与装饰：辅助传达风格，但不应抢占信息主视觉。

- **图层与对齐**  
  - 善用图层顺序管理前后关系（背景 / 数据 / 装饰）。  
  - 使用对齐工具（居中 / 网格 / 等间距）保证布局整洁。  
  - 尽量遵守「对齐—对比—留白」三大基础视觉原则。

- **字体与颜色规范**  
  - 字体：优先使用可读性强的无衬线字体，避免过度花哨。  
  - 颜色：
    - 文字与背景保持足够对比，支持在强光环境下可读。  
    - 控制全局主色 1–2 个，辅助色 2–3 个即可。  
  - 如 Wristo 提供官方字体与色板，请优先参考《设计规范》文档。
