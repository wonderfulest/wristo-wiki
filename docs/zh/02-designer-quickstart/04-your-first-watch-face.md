# 第一个表盘（Your First Watch Face）

> 这是整个快速开始中最关键的一节，建议跟着一步一步做完。

- **创建第一个表盘**  
  - 在控制台点击「新建表盘」或类似入口。  
  - 为项目命名（例如：`My First Wristo Watchface`）。

- **选择设备与分辨率**  
  - 从支持的设备列表中选择目标设备（如某款 Garmin 机型）。  
  - 对应分辨率会自动带出，也可在后续阶段配置多分辨率适配。

- **使用模板 vs 从空白开始**  
  - 使用模板：
    - 适合第一次上手，快速理解布局与组件。  
    - 选择一个接近你目标风格的模板，替换图片与颜色即可。  
  - 从空白开始：
    - 适合有成熟设计方案或较强设计经验的用户。  
    - 自行规划网格、排版和信息层级。

- **保存与预览**  
  - 在编辑器中完成基础设计后，点击「保存」。  
  - 使用内置预览功能查看表盘在目标设备上的展示效果。  
  - 建议在每次关键修改后都进行一次预览，避免后期返工。
