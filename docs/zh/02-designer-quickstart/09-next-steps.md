# 发布与后续（Next Steps）

- **发布到平台（以 Garmin 为例）**  
  - 按照平台流程上传资源包与配置文件。  
  - 填写表盘名称、简介、标签、预览图等信息。  
  - 提交审核并等待平台结果。

- **表盘更新与版本管理**  
  - 每次更新表盘建议：
    - 在 Wristo 中保留历史版本（或使用版本号管理）。  
    - 在配置文件中更新版本号与更新说明。  
  - 避免直接覆盖线上版本而不留备份，便于回滚。

- **用户反馈与迭代建议**  
  - 根据用户评价与数据（下载量、留存等）调整设计。  
  - 建议以小步快跑方式迭代：一次只改少量关键点，持续观察效果。

- **商业化路径（如果有）**  
  - 若平台支持付费表盘或内购：
    - 关注定价策略与目标人群。  
    - 平衡个性化设计与大众审美。  
  - 具体规则与分成方式请参考《设计师入驻规则》《设计师入驻落地方案》等文档。
