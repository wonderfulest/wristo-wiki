# 预览、导出与测试（Preview & Export）

- **在线预览**  
  - 使用编辑器内的预览功能检查整体排版、颜色与数据位置。  
  - 建议在不同比例（缩放）下预览，模拟真实佩戴距离。

- **不同设备适配检查**  
  - 若一个表盘支持多设备分辨率：
    - 逐一检查每种分辨率下是否有元素被裁切或遮挡。  
    - 核对安全区域与边缘留白。  
  - 必要时为不同分辨率制作微调版本。

- **导出配置（如 `conf.json`）**  
  - 完成设计后，根据平台要求导出配置和资源包。  
  - `conf.json` 等配置文件中通常包含：分辨率、数据绑定、资源路径等信息。  
  - 导出前确保：项目命名规范、版本号更新、平台必填字段已完整。

- **测试常见问题**  
  - 模拟器显示正常但真机异常：检查设备型号、系统版本与权限。  
  - 动画 / 动态效果卡顿：尝试减少图层数量、压缩图片、简化逻辑。  
  - 颜色偏差：在真实户外环境下观察，以便调整对比度与亮度。
