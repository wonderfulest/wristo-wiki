# 设计师入门（Getting Started）

- **Wristo 是什么？**  
  Wristo 是一个面向设计师与开发者的「表盘设计与发行平台」，帮你把创意快速变成可在各大智能手表平台（如 Garmin 等）运行的表盘产品。

- **我可以在 Wristo 做什么？**  
  - 设计并管理多个表盘项目。  
  - 使用可视化编辑器完成布局、配色、字体等设计工作。  
  - 绑定数据字段（步数、心率等），制作既好看又好用的表盘。  
  - 导出并发布到支持的平台，持续维护和更新。

- **支持哪些设备与平台？（示例）**  
  - Garmin 系列设备（不同分辨率与机型）。  
  - 后续会根据平台支持情况持续扩展（以实际文档为准）。

- **谁适合使用 Wristo？**  
  - 设计师：有 UI/视觉基础，希望快速做出可上架的表盘。  
  - 开发者：需要在现有表盘上定制视觉与交互。  
  - 商家 / 品牌方：希望打造品牌专属表盘资产。
