# 控制台快速认识（Dashboard Overview）

本节不讲具体按钮在哪里点，而是先帮你厘清 Wristo 的两个核心系统：

- 设计工具：`https://studio.wristo.io/`
- 商家系统：`https://merchant.wristo.io/`

---

## 1. 设计工具 · Wristo Studio（studio.wristo.io）

- **定位**  
  Wristo Studio 是设计师的日常工作台，你可以在这里：
  - 管理表盘项目与版本。  
  - 使用可视化编辑器进行创作（布局、样式、数据绑定等）。  
  - 上传和管理图片、字体等设计资源。  
  - 进行预览、导出配置，为发布做准备。

- **适合谁用？**  
  - 需要亲自参与设计与制作表盘的设计师。  
  - 想要掌控视觉细节与交互效果的创作者。

- **典型使用场景**  
  1. 登录 `studio.wristo.io`。  
  2. 创建 / 打开一个表盘项目。  
  3. 在编辑器中完成设计与数据配置。  
  4. 预览并导出用于发布的配置与资源包。

---

## 2. 商家系统 · Wristo Merchant（merchant.wristo.io）

- **定位**  
  Wristo Merchant 是面向设计师 / 商家的运营与数据平台，你可以在这里：
  - 查看表盘作品的下载量、使用情况。  
  - 查看和管理收益相关数据（如平台支持）。  
  - 管理上架中的作品信息（名称、描述、价格、版本等）。

- **适合谁用？**  
  - 已经有上线作品，希望关注数据表现与收益的设计师。  
  - 负责整体运营和商业化的商家 / 品牌方。

- **典型使用场景**  
  1. 登录 `merchant.wristo.io`。  
  2. 在作品列表中查看各个表盘的下载量、留存等核心指标。  
  3. 根据数据表现调整价格、描述、上架策略。  
  4. 定期查看收益结算与相关报表（以平台实际支持为准）。

---

> 小结：
> - `studio.wristo.io`：创作与配置表盘的「设计工作台」。  
> - `merchant.wristo.io`：查看数据、收益与运营表现的「商家控制台」。  
> 建议先在 Studio 中完成作品创作，再结合 Merchant 中的数据做后续迭代与运营决策。
