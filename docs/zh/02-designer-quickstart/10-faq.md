# 常见问题（FAQ）

> 以下为新手设计师常见疑问的示例，具体问题可在后续不断补充完善。

- **Q1：第一次做表盘，推荐从哪里开始？**  
  A：建议从「模板 + 少量自定义」开始，先把一次完整的创建—预览—导出—发布流程跑通，再去做复杂创意。

- **Q2：为什么模拟器里很好看，真机上效果一般？**  
  A：可能原因包括：屏幕实际亮度与对比度、户外强光环境、表带与肤色搭配、分辨率缩放等。建议多在真机、多场景下观察，并预留足够对比度和留白。

- **Q3：表盘卡顿或耗电严重怎么办？**  
  A：检查是否存在：
  - 大量超大尺寸 PNG 或复杂透明叠加。  
  - 过多高频动画或实时刷新元素。  
  - 不必要的数据计算逻辑。  
  尝试精简资源与逻辑，优先保证核心信息体验。

- **Q4：设备上显示的数据不对 / 不更新？**  
  A：
  - 确认设备本身是否有记录相应数据。  
  - 检查数据绑定是否正确。  
  - 确认平台权限、同步状态是否正常。

- **Q5：有 Bug 或显示异常如何反馈？**  
  A：
  - 先记录设备型号、系统版本、表盘版本、问题截图或视频。  
  - 按文档中提供的渠道（工单系统 / 邮箱 / 社群）提交。  
  - 建议附上导出的配置文件或项目信息，便于排查。
