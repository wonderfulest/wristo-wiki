# 数据与动态元素（Data & Logic）

- **数据字段说明（示例）**  
  - 步数、心率、卡路里、楼层、距离、电量、天气等。  
  - 不同平台支持的数据字段可能有所不同，请以平台文档为准。

- **数据绑定方式（概念）**  
  - 在编辑器中选中组件（如文本），将其绑定到对应数据字段。  
  - 可设置显示格式（如 24/12 小时、单位、前缀/后缀）。

- **条件显示与状态切换（如果平台支持）**  
  - 根据设备状态（运动中/静止、白天/夜间、电量高/低）切换不同样式。  
  - 用于实现例如：低电量简化模式、夜间深色模式等。  
  - 详细配置方式请参考后续高级教程或平台文档。

- **常见数据异常说明**  
  - 数据为空 / 为 0：可能是设备当天未记录、权限未授权或模拟器环境限制。  
  - 与真机不一致：注意模拟器、历史数据与实时数据之间的差异。  
  - 建议在真机多场景测试，包括运动 / 静止、白天 / 夜间等。
