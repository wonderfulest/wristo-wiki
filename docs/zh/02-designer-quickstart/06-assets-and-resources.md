# 使用素材与资源（Assets & Resources）

- **上传图片资源**  
  - 在「资源管理」中上传 PNG/JPG 等图片素材。  
  - 为资源命名时建议使用有语义的英文或拼音（如 `bg-sunset-01`）。

- **使用内置素材**  
  - 若 Wristo 提供官方图标库 / 背景库，可直接在编辑器内搜索和插入。  
  - 内置素材通常已经过尺寸与性能优化，优先推荐使用。

- **图片尺寸与性能建议**  
  - 分辨率：接近或等于目标设备分辨率即可，避免远超分辨率导致包体过大。  
  - 压缩：在保证视觉效果的前提下适度压缩。  
  - 避免使用大量超大 PNG 或半透明叠加，以免影响性能与续航。

- **背景图设计技巧**  
  - 确保时间和关键信息区域有足够对比度。  
  - 避免在时间和数字后面放置高对比度复杂纹理。  
  - 可以为主信息区域单独设计一块「信息底板」，提升可读性。
