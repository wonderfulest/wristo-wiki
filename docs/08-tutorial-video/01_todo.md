## 教学视频方案

> **不出镜 ≠ 冷冰冰**
>  最好的方案是：
>  **「录屏 + 光标引导 + 结构化字幕 + 轻度旁白（可选）」**

这也是 Figma、Notion、GitHub Docs、很多开发者平台在用的标准做法。



## 视频形式：**录屏 + 字幕（无真人）**

**最稳、最工程师友好、最容易持续更新**

**构成：**

- 全程录制 Wristo Studio / Garmin 表盘设计界面
- 鼠标高亮（非常重要）
- 关键步骤配字幕（中英任选）
- 无真人、可无旁白

**适合内容：**

- 注册 / 登录
- 新建表盘
- 拖拽组件
- 修改属性
- 导出 / 发布

👉 **这是你 Wiki 视频的主力形态**



### ✅ 正确方式（工程化拆分）

**每个视频只解决 1 个问题，2–5 分钟**

## 三、每个视频的“标准模板”（你可以固化）

### 视频结构（强烈建议固定）

```
[0–5s]   本视频解决什么问题
[5–15s]  当前场景 / 前置条件
[15–120s] 实操演示
[最后]   常见坑 / 小提醒
```

### 字幕风格（极其重要）

- 短句
- 动词开头
- 不解释原理，只说「怎么做」

例子：

> 点击「Add Time」
> 拖拽到画布中央
> 调整 Font Size = 48
> 设置 Alignment = Center

## 四、工具推荐（不折腾版）

### 🎥 录屏

- **macOS**：CleanShot X / Screen Studio
- **Windows**：OBS（记得开鼠标高亮）

### 🖱 鼠标高亮（一定要有）

- 光标放大
- 点击涟漪
- 拖拽轨迹

### ✍️ 字幕

- 剪映 / CapCut（效率最高）
- 字幕样式统一（白底黑字 or 黑底白字）

### 🤖 AI 配音（可选）

- 中文：剪映 / 腾讯智影
- 英文：ElevenLabs / Azure TTS
