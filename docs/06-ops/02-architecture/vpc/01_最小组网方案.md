一套**最小、稳妥、可扩展**的 AWS 组网方案，专门适合
 👉 **2 台 EC2（一主一备）**
 👉 不追求复杂 HA，但要“能切、好切、不折腾”。

------

## ✅ 推荐方案（90% 场景够用）

### **1 VPC + 2 子网 + 2 EC2（主 / 备）**

### 架构一眼看懂

```
VPC (10.0.0.0/16)
├─ 子网 A（主）10.0.1.0/24
│   └─ EC2-A（主）
│
├─ 子网 B（备）10.0.2.0/24
│   └─ EC2-B（备）
│
└─ Internet Gateway
```

------

## 🧱 组件清单（最小必需）

| 组件             | 数量      | 说明         |
| ---------------- | --------- | ------------ |
| VPC              | 1         | 私有网络     |
| 子网             | 2         | 主 / 备隔离  |
| EC2              | 2         | 主机、备机   |
| Internet Gateway | 1         | 对外访问     |
| 路由表           | 1         | 统一出网     |
| Security Group   | 1         | 统一安全策略 |
| Elastic IP       | 1（可选） | 快速切换     |

------

## 🔌 网络怎么连（关键点）

### 1️⃣ VPC

- CIDR：`10.0.0.0/16`
- 后面扩机器、扩子网不痛苦

------

### 2️⃣ 两个子网（建议不同 AZ）

| 子网   | CIDR          | AZ              |
| ------ | ------------- | --------------- |
| 主子网 | `10.0.1.0/24` | ap-southeast-1a |
| 备子网 | `10.0.2.0/24` | ap-southeast-1b |

👉 不同 AZ = **防单机房故障**

------

### 3️⃣ 路由 & 出网

- 绑定 **Internet Gateway**
- 路由规则：

```
0.0.0.0/0 → IGW
```

------

### 4️⃣ EC2 网络配置

- 两台 EC2 都：
  - 绑定同一个 Security Group
  - 分别在不同子网
- 主机可以绑定 **Elastic IP**

------

## 🔐 Security Group（示例）

```
SSH   22     你的IP
HTTP  80     0.0.0.0/0
HTTPS 443    0.0.0.0/0
```

------

## 🔁 主备是怎么“切”的？

### ⭐ 推荐：Elastic IP 手动切换（最简单）

```
故障时：
Elastic IP → 解绑 EC2-A → 绑定 EC2-B
```

✔ 1 分钟完成
✔ 不需要 LB
✔ 不增加成本

------

### 🚀 进阶（你将来可能会用）

但 **现在不建议**，性价比不高。
